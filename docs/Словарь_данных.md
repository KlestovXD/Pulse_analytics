# Словарь данных «Пульс и риск текучести» (синтетический датасет)

Все идентификаторы обезличены (`EMP00001`, `T01`…), имена и тексты сгенерированы. Персональных данных нет.

## employees.csv — реестр сотрудников

| Поле | Тип | Описание |
|---|---|---|
| `employee_id` | строка | Обезличенный ID сотрудника (`EMP00001`) |
| `team_id` | строка | Команда (`T01`–`T40`) |
| `division` | строка | Дивизион (5 значений) |
| `grade` | строка | Грейд: Специалист / Ведущий специалист / Главный специалист / Руководитель группы |
| `work_format` | строка | Формат работы: офис / гибрид / удалёнка |
| `hire_date` | дата (YYYY-MM-DD) | Дата найма |
| `manager_id` | строка | ID руководителя (`EMP00000` — внешний руководитель команды; руководитель команды — первый сотрудник команды с грейдом «Руководитель группы») |

Текущий статус определяется через `exits.csv`: если сотрудника там нет — он активен на 2026-09-30.

## survey_responses.csv — ответы на пульс-опрос

Одна строка = один ответ. Ответы есть только у участвовавших; участие в волне считайте как долю ответивших от численности (активных на дату волны).

| Поле | Тип | Описание |
|---|---|---|
| `response_id` | строка | ID ответа |
| `wave` | строка | Волна: `2026-03`, `2026-06`, `2026-09` |
| `employee_id` | строка | Ссылка на сотрудника |
| `submitted_at` | дата (YYYY-MM-DD) | Дата отправки ответа |
| `q_conditions` | 1–10 | Условия труда |
| `q_recognition` | 1–10 | Признание вклада |
| `q_growth` | 1–10 | Развитие и обучение |
| `q_manager` | 1–10 | Руководитель |
| `q_pay` | 1–10 | Оплата труда (бывают пропуски) |
| `q_balance` | 1–10 | Баланс работа/жизнь |
| `q_goals` | 1–10 | Цели и смысл |
| `q_tools` | 1–10 | Инструменты и процессы |
| `q_recommend` | 0–10 | «Порекомендовал бы банк как работодателя» (основа eNPS) |

## exits.csv — увольнения

| Поле | Тип | Описание |
|---|---|---|
| `employee_id` | строка | Ссылка на сотрудника |
| `exit_date` | дата (YYYY-MM-DD) | Дата увольнения (окно: 2025-09-01 — 2026-09-30) |
| `exit_reason` | строка | Причина из заявления/выходного интервью |
| `exit_type` | строка | Добровольный / вынужденный |

## market_context.csv — рыночные ориентиры (внешний контекст)

Подборка рыночных бенчмарков, которую собрал предыдущий аналитик. Одна строка = один ориентир.

| Поле | Тип | Описание |
|---|---|---|
| `source` | строка | Источник (обзор/монитор) |
| `metric` | строка | Метрика: текучесть, текучесть добровольная, доля добровольных увольнений, eNPS, индекс вовлечённости, стоимость замещения |
| `scope` | строка | Сегмент рынка (отрасль/группа компаний) |
| `period` | строка | Период данных |
| `value` | число | Значение ориентира |
| `unit` | строка | Единица (%, п.п., балл 0–100, % годовой ЗП) |
| `methodology` | строка | Методика расчёта, как её описал источник |

Внимание: ориентиры собраны из разных источников — определения, шкалы и периоды различаются; часть подборки не обновлялась. Перед сопоставлением с нашими данными проверьте сопоставимость.

## Известные особенности данных

- Источник неидеален: возможны технические дубли, пропуски, разнородные форматы дат, «осиротевшие» ссылки. Обрабатывайте осознанно.
- Опрос анонимный по правилам компании, но выгрузка идёт с `employee_id` для аналитики — учитывать, что участие добровольное и может различаться между группами.
- `work_format` — самообъявленный формат сотрудника; распределение форматов неоднородно между командами.
- Некоторые команды малочисленны (<10 человек) — осторожно с процентами.
- Данные полностью синтетические и сгенерированы детерминированно (seed 42); генератор приложен в `generator/` для прозрачности.
