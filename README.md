# Пульс сотрудников и риск текучести

Тестовое исследование для HR-аналитики Сбера. Цель — понять, как меняются оценки сотрудников, какие проблемы стоит проверить в первую очередь и как ответы опроса связаны с последующими увольнениями. **Все сведения о сотрудниках, ответы и комментарии синтетические.** Публичные банковские раскрытия собраны отдельно и используются как внешний контекст.

## Основные выводы

- С марта по сентябрь 2026 года участие снизилось с **80,0% до 74,3%**. Средняя вовлеченность выросла на **0,88 балла**, а у сотрудников с оценками в обеих волнах изменение составило **−0,13 балла**. Убедительных признаков улучшения вовлеченности в парной выборке нет.
- У сотрудников, ответивших в марте и сентябре, индекс готовности рекомендовать работодателя (eNPS) снизился на **9,79 пункта**. Среди участников всех трех волн направление совпало, но оценка менее определенная.
- Текучесть за 01.10.2025–30.09.2026 составила **14,42%**, добровольная — **13,12%**. У розничного блока самые высокие показатели среди дивизионов: **20,19%** и **18,60%** соответственно. Обе ставки по всей организации ниже раскрытий Банка ДОМ.РФ и ВТБ за 2025 год. Положение относительно банковского рынка остается неопределенным.
- Оплата и нагрузка — самые частые темы отрицательных и смешанных комментариев. Упоминания сопутствовали более низким оценкам оплаты и баланса работы и жизни среди авторов комментариев.

## Данные и устройство проекта

В `data/raw/` пять CSV: кадровый реестр, ответы и комментарии трех волн, увольнения и синтетические рыночные ориентиры. [Словарь данных](docs/Словарь_данных.md) описывает структуру. Снимок проверенных публичных источников находится в `data/reference/`.

| Путь | Назначение |
| --- | --- |
| `src/` | Аудит, подготовка таблиц, метрики, проверка сохраненной разметки и сборка панели на Python |
| `data/processed/` | Аналитические таблицы, сохраненная модельная и контрольная разметка, манифесты с контрольными суммами |
| `dashboard/` | Шаблон, стили и логика сборки, готовая автономная панель |
| `prompts/`, `.agents/skills/` | Версионированная схема комментариев и навык для следующей волны |
| `tests/` | Автоматические проверки данных, расчетов, разметки и конфиденциальности панели |

Подробные результаты: [аудит данных](reports/data_quality.md), [количественный анализ](reports/quantitative_analysis.md), [анализ комментариев](reports/comment_analysis.md), [рыночные сравнения](reports/market_analysis.md) и [проверка панели](reports/dashboard_validation.md).

## Воспроизведение

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.12. Установка использует версии из [uv.lock](uv.lock). Из корня репозитория выполните:

```sh
uv sync --locked
uv run --no-sync python -m src.pulse_quality
uv run --no-sync python -m src.pulse_analysis
uv run --no-sync python -m src.pulse_comments analyze --review data/processed/comment_analysis/manual_review_filled.csv
uv run --no-sync python -m src.pulse_dashboard build
```

Команды обновляют производные таблицы, отчеты и `dashboard/index.html`. Исходные CSV открываются на чтение. Анализ комментариев использует сохраненные метки и проверенную человеком разметку. Ключ и обращение к Gemini для этих расчетов не нужны. Для новой выгрузки используйте [инструкцию запуска навыка](docs/hr_pulse_comments_skill.md).

Автоматические тесты после установки зависимостей:

```sh
uv run --no-sync python -m unittest discover -s tests -v
```

## Ограничения

Добровольное участие влияет на состав выборки. Анализ за 90 дней доступен для мартовской и июньской волн, а связь с увольнением носит наблюдательный характер. Разметка комментариев проверена на знакомых синтетических формулировках и может пропускать серьезные проблемы. Банковские сравнения описывают два конкретных раскрытия с различиями в периодах, составе персонала и методиках.
