# «Пульс и риск текучести». Количественный анализ

С марта по сентябрь средняя вовлечённость среди участников изменилась с **61,74 до 62,62**. Изменение у сотрудников с валидной оценкой в обеих волнах составило **−0,13 [−0,91…0,65] балла** при 511 валидных парах. Интервал парной оценки включает ноль. Рост среднего по всем участникам требует учёта состава ответивших. Участие по волнам изменилось с 80,0% до 74,3%.

Общая годовая текучесть составила **14,42%**, добровольная — **13,12%**. Для мартовских и июньских участников отношение шансов уйти в следующие 90 дней на дополнительные 10 баллов вовлечённости составило **0,82 [0,69…0,98]** после учёта волны.

## Ограничения и воспроизводимость

- Состав команд восстановлен по единственному реестру. Истории переводов, изменений грейда и повторного найма в выгрузке нет. Даты волн взяты из аудита по наблюдаемой отправке.

- Проверка связей и команд использует несколько сравнений. Сигналы требуют проверки на новых волнах.
- Для годовой текучести доступны фактические события и экспозиция. Интервалы выборочной погрешности для этой описательной административной метрики не рассчитывались.
