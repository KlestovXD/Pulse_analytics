# Реестр метрик «Пульс и риск текучести»

Волны датированы 16.03, 15.06 и 14.09.2026 по наблюдаемой дате отправки. Для срезов по волнам активные сотрудники удовлетворяют условию `hire_date ≤ дата волны < exit_date`. При отсутствии увольнения применяется статус из словаря. Учитываются версии, отправленные к дате волны. При анализе 90-дневного окна началом служит дата последней версии, вошедшей в сведение конкретного ответа.

## Сведение, динамика и неопределённость

- По каждому вопросу сохраняется единственная различимая валидная оценка, включая случай, когда в другой версии оценки нет. Несколько разных валидных оценок на одну пару получают статус `conflict`. Отсутствие валидных значений получает статус `missing` или `invalid`. В метриках эти три состояния считаются пропусками. Соответствие сырым версиям хранится в `survey_lineage.csv`.
- Уровни расчёта волн — весь блок, дивизион и команда. Изменение к предыдущей волне равно позднему значению минус раннее. Для участия разница выражена в процентных пунктах, для индексов и тем — в пунктах соответствующей шкалы. Годовая текучесть относится к одному фиксированному периоду, поэтому годовая динамика к волнам не рассчитывается. В командной таблице годовой итог размещён в строке последней волны с собственными датами окна.
- Индивидуальное изменение равно поздней оценке минус ранняя. Метрика изменения равна сумме индивидуальных разниц, делённой на число пар с валидными оценками с обеих сторон. Для проверки устойчивости март–сентябрь отдельно берутся участники всех трёх волн. Численность и доли активных и ответивших используются для сравнения состава по дивизиону, грейду и формату работы.
- У изменения общих средних по вовлечённости есть два разложения. Парное изменение плюс отклонения парной и полной выборок на каждой дате восстанавливает общий сдвиг. Для дивизионов с общим покрытием применяется симметричное разложение. Внутридивизионная часть равна сумме `(p₀+p₁)/2 × (m₁−m₀)`, часть состава — сумме `(m₀+m₁)/2 × (p₁−p₀)`, где `p` — доля дивизиона среди валидных ответов, `m` — его средняя оценка.
- Для средних и парных изменений рассчитан ориентировочный 95%-ный нормальный интервал на основе стандартной ошибки. Для уровня средних применяются границы шкалы. Для доли участия и риска по отдельной волне рассчитан интервал Уилсона. Для объединённых долей риска используется процентильный бутстрэп по сотрудникам с 1 500 повторениями. При наблюдаемых 0% или 100% применяется интервал Уилсона по числу уникальных сотрудников. Для разностей оценок и логистических моделей используется кластерная оценка ошибки по сотруднику. При малом числе событий интервалы могут быть нестабильны.
- Сравнения риска по категориям описательные. Логистическая регрессия использует одно значение опроса и индикатор волны. Для чувствительности используется восьмитемный индекс, четырёхтемный индекс на той же подвыборке, индивидуальный сигнал рекомендации и отдельные оценки по волнам. Минимум 10 сотрудников с исходом на коэффициент признака или волны применяется как рабочий порог. Совместная модель с подразделением, форматом и грейдом требует больше исходов. Связи не устанавливают причинный эффект.
- Для агрегатов с менее чем 10 уникальными ответившими скрываются численные детали. Средние и парные изменения дополнительно требуют соответственно 10 валидных ответивших и 10 валидных пар. Командный сигнал строится только по парному снижению вовлечённости. Верхняя граница 95%-ного интервала ниже нуля обозначает сигнал для разбора. Поправка на множественные сравнения для этого предварительного отбора не применяется.
